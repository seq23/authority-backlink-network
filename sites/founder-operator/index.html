What you will find here

The library organizes resources for founders and operators who are building companies, managing teams, using AI, producing events, or trying to improve personal execution. Each topic page is intended to explain the operating problem before pointing to a related resource. That order matters: a link should support a decision, not replace the explanation a reader came to find.

Coverage includes executive coaching systems, founder routines, AI-enabled marketing operations, and virtual production. These categories share a common question: how can a small team create repeatable work without losing judgment, accountability, or control of the customer experience?

How to evaluate a resource

  • Define the result you need before comparing features.
  • Identify the people, data, and approvals involved.
  • Ask how the system behaves when a dependency fails.
  • Check whether pricing and implementation effort match the expected value.
  • Preserve an exit path and access to your own records.
