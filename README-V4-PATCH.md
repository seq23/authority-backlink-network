# Authority Network V4 Programmatic Pantry Patch

Upload this patch to the root of your `authority-network` repo. It adds the one-year autopilot pantry and workflow.

## Install

1. Unzip.
2. Upload/merge contents into repo root.
3. Commit to `main`.
4. GitHub → Settings → Actions → General → Workflow permissions → Read and write.
5. GitHub → Actions → Authority Network V4 Autopilot → Run workflow.

## No required secrets

The baseline engine is $0 and deterministic.

Optional: add `GEMINI_API_KEY` if you want free-tier polish.
