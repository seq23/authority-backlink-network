# Day 1 Launch Procedure

1. Buy or choose the three publication domains:
   - founderoperatorlibrary.com
   - memphisvendorlibrary.com
   - professionalresourcelibrary.com

2. Create one GitHub repo from this folder.

3. Connect three Cloudflare Pages projects:
   - authority-founder → `sites/founder-operator`
   - authority-memphis → `sites/memphis-local`
   - authority-professional → `sites/professional-resources`

4. Add Cloudflare secrets to GitHub.

5. Run `npm run check` locally or through GitHub Actions.

6. Deploy.

7. Submit each sitemap to Google Search Console and Bing Webmaster Tools.

8. Do not turn on social auto-posting until API keys, approval gates, and platform rules are reviewed.
