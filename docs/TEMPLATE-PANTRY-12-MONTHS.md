# 12-Month Template Pantry

The V4 pantry is not a flat list of 69 topics. It is a combinatorial system using:

- 15 page formats
- 12 search/answer intents
- 16 editorial modifiers
- publication-specific audiences
- publication-specific topic clusters
- publication-specific paragraph, FAQ, checklist, and social hooks

Estimated combinations per publication:

- Founder/Operator: 898,560
- Memphis Local: 898,560
- Professional Resources: 1,123,200

This is enough for a full 365-day run at up to 9 total pages/day, assuming the quality gate continues to pass.

The pantry should still be reviewed quarterly in an ideal world, but it is intentionally built so you do not need to re-up for at least one year.
