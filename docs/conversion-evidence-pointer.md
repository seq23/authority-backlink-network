# Conversion evidence — pointer, not a copy

**Added 2026-08-26.** This repo holds no conversion evidence of its own.

The portfolio keeps exactly **one** conversion evidence record, in a sibling
repo:

```
sprylabs-hpc-site/data/entity/conversion_evidence.json
```

Read it there. Do not copy it into this repo, do not restate its numbers here,
and do not derive new figures from it.

## What it records

Two verified sales of BHPC OS to cold visitors, on two different referring
domains, plus two excluded test transactions. It also records an open question
about whether either sale was at full price, which is unresolved.

## What it does not support

Two data points across two domains support a documented fact, not a reproducible
pattern. It is **not** a conversion rate, a funnel model, or a reference funnel —
there is no analytics denominator behind it. Any page, report, doc or generated
claim in this repo that implies a conversion rate, a repeatable funnel, or a
performance benchmark is unsupported by this evidence and should not ship.

If new conversion evidence appears, add it to the record in sprylabs-hpc-site
rather than starting a second one here. One record, one place.
