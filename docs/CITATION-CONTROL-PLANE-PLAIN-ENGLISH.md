# Citation Control Plane — Plain English

This repo helps the user's businesses earn more visibility by publishing useful resource pages on separate authority sites and linking those pages to the most relevant owned product.

The product sites also create their own pages. Those pages are owned content surfaces. The Authority Network pages are external editorial support. Both contribute to the larger citation/impression objective, but they are counted separately.

The system does five simple things:

1. keeps a list of brands and approved destinations;
2. gives every brand a growth profile;
3. favors brands that have received less coverage;
4. records each backlink and what evidence exists;
5. produces one portfolio dashboard.

Targets are guidance. They are not petty blockers. A page is blocked only for real problems such as false evidence, wrong-domain routing, corruption, unsafe claims, or a broken required link.

Useful commands:

```bash
npm run citation:dashboard
npm run citation:verify-repo
npm run citation:import-manifests
npm run validate:release
```
